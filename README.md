# Tab Manager

[English](#english) | [中文](#中文)

## English

A lightweight Chrome extension for saving and restoring tab sessions with one click. Keep your browser organized without complexity.

### ✨ Features

- **One-Click Save** - Save all current tabs as a named session instantly
- **One-Click Restore** - Reopen all tabs from a saved session
- **Simple Interface** - Clean, intuitive design with no learning curve
- **Local Storage** - All data stored locally in your browser
- **No Account Required** - Works immediately, no sign-up needed
- **Privacy First** - No data collection, no external servers
- **Lightweight** - Minimal resource usage

### 🎯 Use Cases

**Work-Life Balance**
- Save "Work" session before leaving office
- Restore "Personal" session for evening browsing
- Keep contexts separate and organized

**Research & Study**
- Save research sessions with dozens of tabs
- Restore specific project tabs when needed
- Never lose important references

**Project Management**
- One session per project
- Quick context switching between projects
- Clean workspace for focused work

**Browser Cleanup**
- Save tabs before closing browser
- Reduce memory usage by closing unused tabs
- Restore when needed

### 🚀 Installation

#### From Source

1. Clone or download this repository:
   ```bash
   git clone https://github.com/NoahWorld/simple-tab-manager.git
   ```

2. Open Chrome and navigate to `chrome://extensions/`

3. Enable **Developer mode** (toggle in top-right corner)

4. Click **Load unpacked** and select the extension folder

5. The extension icon will appear in your toolbar

### 📖 Usage

#### Save Current Tabs

1. Click the extension icon
2. Enter a session name (e.g., "Work", "Research", "Shopping")
3. Click **Save** button
4. All current tabs are saved

#### Restore a Session

1. Click the extension icon
2. Find the session you want to restore
3. Click **Restore** button
4. All tabs from that session will open

#### Delete a Session

1. Click the extension icon
2. Find the session you want to delete
3. Click **Delete** button
4. Session is permanently removed

### 🔒 Permissions

- **tabs** - Required to read current tabs and create new tabs
- **storage** - Required to save sessions locally in your browser

### 📝 Privacy

This extension:
- ✅ Does NOT collect any data
- ✅ Does NOT send data to external servers
- ✅ Stores everything locally in your browser
- ✅ Does NOT track your browsing
- ✅ Does NOT require account or login

### 💡 Tips

- Use descriptive names for easy identification
- Sessions are sorted by creation date (newest first)
- Each session shows tab count and creation time
- Restoring a session opens tabs in new tabs (doesn't close current ones)

### 🛠️ Technical Details

- Built with Manifest V3
- Uses Chrome Storage API for local persistence
- Minimal permissions for maximum privacy
- No external dependencies

一个轻量级的 Chrome 扩展，用于一键保存和恢复标签页会话。让你的浏览器保持整洁有序。

### ✨ 功能特性

- **一键保存** - 立即将所有当前标签页保存为命名会话
- **一键恢复** - 重新打开已保存会话的所有标签页
- **简洁界面** - 清爽直观的设计，无需学习
- **本地存储** - 所有数据存储在浏览器本地
- **无需注册** - 立即可用，无需注册账号
- **隐私优先** - 不收集数据，无外部服务器
- **轻量级** - 最小资源占用

### 🎯 使用场景

**工作生活平衡**
- 下班前保存"工作"会话
- 晚上恢复"个人"会话
- 保持不同场景分离和有序

**研究学习**
- 保存包含数十个标签页的研究会话
- 需要时恢复特定项目标签页
- 永不丢失重要参考资料

**项目管理**
- 每个项目一个会话
- 快速在项目间切换
- 保持工作区整洁专注

**浏览器清理**
- 关闭浏览器前保存标签页
- 关闭未使用的标签页以减少内存占用
- 需要时恢复

### 🚀 安装方法

#### 从源码安装

1. 克隆或下载此仓库：
   ```bash
   git clone https://github.com/NoahWorld/simple-tab-manager.git
   ```

2. 打开 Chrome 浏览器，访问 `chrome://extensions/`

3. 开启右上角的**开发者模式**

4. 点击**加载已解压的扩展程序**，选择扩展文件夹

5. 扩展图标将出现在工具栏中

### 📖 使用说明

#### 保存当前标签页

1. 点击扩展图标
2. 输入会话名称（如"工作"、"研究"、"购物"）
3. 点击**保存**按钮
4. 所有当前标签页已保存

#### 恢复会话

1. 点击扩展图标
2. 找到要恢复的会话
3. 点击**恢复**按钮
4. 该会话的所有标签页将打开

#### 删除会话

1. 点击扩展图标
2. 找到要删除的会话
3. 点击**删除**按钮
4. 会话被永久删除

### 🔒 权限说明

- **tabs** - 读取当前标签页和创建新标签页所需
- **storage** - 在浏览器本地保存会话所需

### 📝 隐私政策

本扩展：
- ✅ 不收集任何数据
- ✅ 不向外部服务器发送数据
- ✅ 所有内容存储在浏览器本地
- ✅ 不追踪你的浏览行为
- ✅ 不需要账号或登录

### 💡 使用技巧

- 使用描述性名称便于识别
- 会话按创建日期排序（最新的在前）
- 每个会话显示标签页数量和创建时间
- 恢复会话会在新标签页中打开（不会关闭当前标签页）

### 🛠️ 技术细节

- 使用 Manifest V3 构建
- 使用 Chrome Storage API 本地持久化
- 最小权限以保护隐私
- 无外部依赖
